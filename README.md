# 工作维度目标管理系统

面向部门负责人的单角色网页应用，围绕“部门目标 → 月度拆解 → 月度跟进 → 周度执行 → 个人 To-Do → 周报/月报”工作链路构建。

## 运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 当前完成情况

### Phase 1：已完成

- Vite 基础架构与五个固定业务页面。
- `GoalVersion`、`Board`、`Project`、`ProjectHistory`、月/周跟进、To-Do、报告与溯源数据模型。
- 独立的浏览器 `localStorage` 数据访问层，刷新后数据保留。
- 三个不可编辑的固定板块。

### 已打通的核心能力

- 上传新版部门目标、创建版本、比较当前专项并归档退出专项，历史记录不删除。
- 月度目标拆解；组员月报识别、周记录比对与去重整合。
- 组员周报从个人维度归入专项维度，生成周会跟进与纪要记录。
- 月历 To-Do 新增、完成、删除，并作为报告数据源。
- 周报/月报生成及原始来源展示。

### 当前模拟能力

OCR 已抽离为 `ocrService.js` 标准适配层。文本文件会真实读取、解析；图片、PDF、Office 文件当前保存文件元信息并返回待识别文本，后续可仅替换 `extractText` 适配器接入真实 OCR API，不影响业务层。

## 下一阶段

接入真实 OCR 服务，增强专项名称变更识别与人工校正界面，并补齐更细粒度的历史版本查看。
